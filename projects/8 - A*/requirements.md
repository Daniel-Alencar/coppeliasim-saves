# Practical Assignment: A* Navigation to a Banana in CoppeliaSim

## Objective

Implement the A* path planning algorithm to navigate a mobile robot from its
initial position to a selected banana while avoiding poop obstacles.

The planned path must be executed using the ROS 2 position control node
developed in the previous exercise.

## 1. Scene Preparation

- Use the CoppeliaSim scene `a_start_banana.ttt`, put the scene in the same
  previous folder.
- The scene contains multiple bananas and poop obstacles. For this assignment,
  select only one banana as the navigation target.
- Use the CoppeliaSim ZeroMQ Remote API to retrieve the robot's position,
  obstacle positions, and banana positions. Do not hard-code object
  coordinates.

## 2. Required Tasks

### Task 1 – Scene Information

- Retrieve the robot's initial position and orientation.
- Identify the poop obstacles and their positions.
- Select a banana as the target using its API path (e.g., `/bananas/Banana[0]`).
- Retrieve object information dynamically from the scene hierarchy.

### Task 2 – Occupancy Grid Map

- Create a 2D grid representation of the environment.
- Define the grid resolution and environment boundaries.
- Represent poop obstacles as occupied regions.
- Inflate obstacles according to the robot's dimensions and an appropriate
  safety margin.
- Ensure that the planned path provides sufficient clearance for the robot.

### Task 3 – A* Path Planning

Implement the A* algorithm to find a collision-free path from the robot's
initial position to the selected banana.

### Task 4 – Robot Navigation

Use the position control node implemented in the previous exercise to execute
the path generated by A*.

- Convert the planned path into a sequence of waypoints.
- Send each waypoint to the existing position control node through the ROS 2
  topic `myRobot/goal`.
- The existing position controller must handle the robot's motion and generate
  the necessary velocity commands.
- Advance to the next waypoint only after the robot reaches the current one
  within a defined tolerance.
- Stop the robot when it reaches the selected banana.
- Ensure that the planner and position controller use the same coordinate
  frame.

> You must reuse the previously developed position controller. Do not implement
> a new robot motion controller for this assignment.

## 3. Experiments and Discussion

Perform the following experiments:

- **Successful navigation:** Demonstrate the robot reaching the selected banana
  without colliding with obstacles.
- **Grid resolution comparison:** Repeat the experiment using a different grid
  resolution and compare the resulting path and navigation behavior.
- **Unreachable destination:** Demonstrate how the algorithm handles an invalid
  or unreachable goal.

Briefly discuss how grid resolution, obstacle inflation, and waypoint tolerance
affect the robot's navigation.
