# 📚 Homework Activity – YOLO-Based Potential Field Navigation

In this exercise, you will control myRobot in CoppeliaSim using ROS2, YOLO, Kinect RGB-D sensing, and the Potential Field algorithm.

---

## Objective

The robot must autonomously navigate through the environment to:

- Detect bananas with YOLO and use them as navigation targets.

- Detect donuts/poops with YOLO and treat them as obstacles.

- Use the Kinect depth image to estimate the 3D position of detected objects.

- Maintain persistent lists of previously detected bananas and obstacles, so objects remain known even when they are no longer visible.

- Avoid inserting the same object multiple times when it is detected again.

- Use an attractive potential toward the selected banana.

- Use repulsive potentials generated by the detected obstacles.

- Combine these forces to determine the robot's desired motion.

- Convert the resulting direction into left and right wheel velocities.

- Mark a banana as collected when the robot reaches it and automatically select another detected banana.

- Continue searching for new bananas when no uncollected target is currently known.

---

## Important

> Unlike the previous exercise, the positions of bananas and obstacles must not be obtained from predefined CoppeliaSim signals or manually specified coordinates.

The expected pipeline is:

```
Kinect RGB-D → YOLO detection → 3D object position → persistent object map → Potential Field → differential-drive control
```

The robot trajectory must emerge from the attractive and repulsive forces. Predefined paths or waypoint sequences are not allowed.

You may use and adapt the provided `yolo_detector` implementation as a starting point.
